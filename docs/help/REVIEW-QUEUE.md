**The tool never touches `last_reviewed`.** It stamps `last_refreshed_against` (the window and concepts it checked, by machine) and nothing else. `last_reviewed` moves only when a person has read the prose: read the linked PRs, confirm the doc still matches what a user sees, edit the prose if it drifted, then set `last_reviewed` yourself. A doc whose `last_refreshed_against` is current but whose `last_reviewed` is old is *checked by machine, not read by a person* — that is what the state on each heading says. A `last_reviewed` date written by an earlier bot run is marked as such and does not count as a human read.
