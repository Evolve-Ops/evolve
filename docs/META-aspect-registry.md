# Aspect registry — Evolve

> **This is Evolve's OWN aspect registry.** The META substrate resolves it via
> `registry_path` in [`.claude/meta.json`](../.claude/meta.json), so the `/meta`
> `/status` `/design` skills read the rows below. A different project that adopts the
> substrate (via `tools/meta-substrate-sync`) keeps its **own** registry at its own
> `registry_path` — never this one; Evolve's aspects are not portable doctrine, the
> *columns* and the *new-aspect protocol* are (they live in
> [`META-session-guide.md`](META-session-guide.md) § "Adding a new META (aspect)").

To add an aspect, append a row here — but first read the new-aspect protocol in
[`META-session-guide.md`](META-session-guide.md) § "Adding a new META (aspect)" (pick a
stable id, seed the spec + memory + `meta-state/<id>.json` ledger). The five per-aspect
parameters each row encodes are defined in that guide's "Per-aspect parameters" section.
