# docs/ — documents live here, by reference

This directory is the Documents app's home in the workspace. The convention,
in one breath: **a document is a file; a reply is a summary and a path; a
revision is a diff; a deliverable is rendered by a script.**

## Layout

```
docs/
  README.md              ← this convention
  <slug>.md              ← the SOURCE of one document (markdown)
  <slug>.pdf, <slug>.html← rendered deliverables, regenerated by `render`
  .revisions/<slug>.json ← revision log: hash + size + diff stats per revision
```

Slugs are lowercase letters, digits and hyphens (`lisbon-trip`,
`q3-board-letter`). One slug, one document, one source of truth.

## The pattern (why this exists)

Writing a document into a chat reply, then re-writing the whole thing for
every "change day 2" request, bills the entire document through the model on
every turn — and through the most expensive model if the conversation runs
there. That was the single most expensive habit in a measured week of
personal-assistant use.

Here the document is a file. The model writes it **once**, then:

- **replies with the summary line** the script prints (title, sections, word
  count, revision, path) — not the document;
- **revises by targeted edit** — `edit <slug> --section "Day 2" --body-file -`
  or `edit <slug> --find "…" --replace "…"` — and relays the diff stats;
- **renders by script** — `render <slug>` writes the PDF and HTML from the
  source, the same content every time (only the footer's render stamp moves);
- **attaches by path** — `docs/<slug>.pdf` is inside the workspace, which is
  where `gmail_send` attachments are allowed to come from;
- **reads a slice, not the file** — `outline <slug>` and
  `show <slug> --section "…"` — when it needs to look before editing.

History carries the path and a content hash per revision, never the text
twice: `log <slug>` shows what changed, when, and by how much.

## Commands

```
python3 scripts/documents.py new <slug> --title "…" --from -        # content on stdin
python3 scripts/documents.py outline <slug>
python3 scripts/documents.py show <slug> --section "Heading"
python3 scripts/documents.py edit <slug> --section "Heading" --body-file -
python3 scripts/documents.py edit <slug> --section "Heading" --append-file -
python3 scripts/documents.py edit <slug> --section "New heading" --create --body-file -
python3 scripts/documents.py edit <slug> --find "old phrase" --replace "new phrase"
python3 scripts/documents.py render <slug>            # docs/<slug>.pdf + .html
python3 scripts/documents.py summary <slug>           # the reply block
python3 scripts/documents.py log <slug>               # revision history
python3 scripts/documents.py list
python3 scripts/documents.py status
```

Every command runs from the workspace root and needs nothing but `python3`.
