# MEMORY.md — {bot_id}

Durable facts about the user(s), preferences, and decisions worth remembering
across sessions. Loaded into every session via OpenClaw's contextFiles
mechanism.

Add an entry only when something is *durable* — a stable preference, an
explicit "remember this" from the user, or a fact that will still be relevant
in three months. Do not log every conversation turn here.

## How to use this file

- One bullet per fact.
- Keep entries short — a fact, not a story.
- If a fact is no longer true, delete the entry rather than annotating it.
- If two facts contradict, the more recent one wins; remove the older one.
